# Portfolio Website - Naidu Ankita

A modern, responsive portfolio built to showcase software engineering skills and academic projects.

## Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Icons & Fonts:** Font Awesome, Google Fonts (Poppins, Montserrat)
* **Deployment:** Git-ready structure

## Core Sections

* **Hero:** Dynamic intro with typewriter effect and social links.
* **Skills:** Categorized cards for Programming (Java, Python, C), Web Dev, and Databases.
* **Education:** Timeline of academic history and CGPA achievements.
* **Projects:** Interactive carousel featuring "Code Sync" and "Crop Prediction System."
* **Experience:** Details on R&D internship at Genpact Ltd. focusing on AI/ML.

## Key Features

* **Fully Responsive:** Optimized for mobile, tablet, and desktop.
* **Themed Design:** Professional emerald green and slate color palette.
* **Quick Navigation:** Smooth-scrolling sticky navbar for easy access.
